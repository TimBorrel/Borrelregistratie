# Borrelregistratie

Een eenvoudige webapplicatie om bij te houden wie wat heeft gedronken tijdens een borrel.

## Functies

- ✅ Voeg deelnemers toe
- ✅ Registreer drankjes per persoon (Bier, Fris, Wijn, Speciaal bier, Overige)
- ✅ Pas prijzen aan per drank
- ✅ Bereken automatisch het totaalbedrag per persoon
- ✅ Bekijk het verbruik per persoon in een overzicht
- ✅ Download het verbruik als CSV/Excel bestand
- ✅ Responsive design (werkt op desktop en mobiel)

## Hoe te gebruiken

1. Open `index.html` in je browser
2. Voeg namen toe van de deelnemers
3. Registreer drankjes door op de + of - knoppen te klikken
4. Bekijk overzichten door de secties uit/in te klappen
5. Download het verbruik als Excel bestand wanneer nodig

## Standaard dranken en prijzen

- Bier: €2.50
- Fris: €2.00
- Wijn: €3.00
- Speciaal bier: €4.00
- Overige: €3.50

Je kunt de prijzen aanpassen in het overzicht "Dranken en prijzen".
